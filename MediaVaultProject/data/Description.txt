Project: MediaVault (CLI Library / Media Manager)
A command‑line app to manage a collection of media items (Books, Movies, Games).
You can add / list / search / sort / check-out / return / save / load items.


What the project does (exact behavior)
You build a command-line application that manages a collection of media items:
✅ Supported item types

Book
Movie
Game

All items share common fields:

id (unique number)
title (string)
addedDate (Date type)
status (enum - Available / CheckedOut / Lost)

Each type adds its own extra fields:

Book → author, pages
Movie → director, minutes
Game → platform (enum - PC/PlayStation/Xbox/Switch)

The project uses an abstract base class Item to represent 
different media types, which enables polymorphism. 
Derived classes like Book, Movie, and Game 
implement specific behavior. The Library class acts as a manager 
that stores and operates on these items using std::unique_ptr,
ensuring safe memory management. I also separated utility functions
into a Utils module to keep the main logic clean and maintainable.

Item → abstract base class + polymorphism
Library → manager / collection handler
unique_ptr → safe ownership + no memory leaks
Utils → separation of concerns
